## Step 3: Determine Execution Order

SubTask 2 depends on SubTask 1 (the bread must be sliced before it can be toasted). Therefore, they must be executed **sequentially**: SubTask 1 first, then SubTask 2.

## Step 4: Minimize Number of Robots

- SubTask 1 needs team {robot2, robot3}
- SubTask 2 needs team {robot1, robot2}

The union of all robots used is {robot1, robot2, robot3} — all three robots are needed because:
- robot3 is the only robot with `SliceObject` (required for SubTask 1)
- robot1 is the only robot with `SwitchOn`/`SwitchOff` (required for SubTask 2)
- robot2 provides `PickupObject`/`PutObject` for both subtasks

No smaller set of robots can cover all required skills across both subtasks.

## Step 6: Execution Code

```python
import time
import threading

def slice_bread():
    # SubTask 1: Slice the Bread — team {robot2, robot3}
    # robot3: GoToObject, PickupObject, SliceObject
    # robot2: GoToObject, PutObject
    GoToObject('Knife')          # robot3
    PickupObject('Knife')        # robot3
    GoToObject('Bread')          # robot3
    SliceObject('Bread')         # robot3
    GoToObject('CounterTop')     # robot2
    PutObject('Knife', 'CounterTop')  # robot2

def toast_bread():
    # SubTask 2: Toast the Bread slice — team {robot1, robot2}
    # robot2: GoToObject, PickupObject, PutObject
    # robot1: GoToObject, SwitchOn, SwitchOff
    GoToObject('Bread')          # robot2
    PickupObject('Bread')        # robot2
    GoToObject('Toaster')        # robot2
    PutObject('Bread', 'Toaster')# robot2
    SwitchOn('Toaster')          # robot1
    time.sleep(5)
    SwitchOff('Toaster')         # robot1
    GoToObject('Bread')          # robot2
    PickupObject('Bread')        # robot2
    GoToObject('Plate')          # robot2
    PutObject('Bread', 'Plate')  # robot2

# Sequential execution: SubTask 1 must complete before SubTask 2
slice_bread()
toast_bread()
```
