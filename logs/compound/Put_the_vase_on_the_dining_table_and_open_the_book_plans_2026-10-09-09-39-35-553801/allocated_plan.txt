# Task Allocation Solution

## Task Decomposition

The task "Put the vase on the dining table and open the book" decomposes into two independent subtasks:

- **SubTask 1: Put the vase on the dining table** — Skills: `GoToObject`, `PickupObject`, `PutObject`
- **SubTask 2: Open the book** — Skills: `GoToObject`, `OpenObject`

These subtasks are independent (no shared objects, no ordering dependency), so they can run **in parallel**.

## Skill & Mass Analysis

**Robots:**
| Robot | Skills | Mass Capacity |
|-------|--------|---------------|
| robot1 | GoToObject, PickupObject, PutObject | 100 |
| robot2 | GoToObject, OpenObject, CloseObject | 100 |

**Relevant object masses:**
- Vase: 1.0
- Book: 0.5
- DiningTable: 85.0 (receptacle, not carried)

## Subtask-to-Robot Matching

**SubTask 1 (Put vase on dining table):**
- Required skills: `GoToObject`, `PickupObject`, `PutObject`
- robot1 possesses **all three** skills. robot2 lacks `PickupObject` and `PutObject`.
- Mass check: Vase = 1.0 ≤ robot1's capacity (100). ✓
- → **Assigned to robot1** (single robot, no team needed).

**SubTask 2 (Open the book):**
- Required skills: `GoToObject`, `OpenObject`
- robot2 possesses **both** skills. robot1 lacks `OpenObject`.
- Mass check: Book = 0.5 ≤ robot2's capacity (100). ✓
- → **Assigned to robot2** (single robot, no team needed).

## Execution Plan

Since the two subtasks are independent and each is handled by a **different** robot, they can execute **in parallel** with no resource contention. This uses the **minimum number of robots (2)** — one per subtask, since neither robot alone has the full skill set for both subtasks.

```python
import threading

def put_vase_on_dining_table():   # robot1
    GoToObject('Vase')
    PickupObject('Vase')
    GoToObject('DiningTable')
    PutObject('Vase', 'DiningTable')

def open_book():                  # robot2
    GoToObject('Book')
    OpenObject('Book')

t1 = threading.Thread(target=put_vase_on_dining_table)  # robot1
t2 = threading.Thread(target=open_book)                 # robot2
t1.start(); t2.start()
t1.join();  t2.join()
```

## Summary

| Subtask | Required Skills | Assigned To | Mass Check | Execution |
|---------|-----------------|-------------|------------|-----------|
| Put vase on dining table | GoToObject, PickupObject, PutObject | robot1 | 1.0 ≤ 100 ✓ | Parallel |
| Open book | GoToObject, OpenObject | robot2 | 0.5 ≤ 100 ✓ | Parallel |

**No teams required** — each subtask is fully covered by a single robot's skills and mass capacity. The two subtasks are independent, so they run in parallel on the two robots, achieving the minimum robot count (2) with maximum concurrency.
